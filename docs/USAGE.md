## 1. 이럴 때 쓰면 좋아요

### 세션 여러 개를 동시에 돌릴 때

터미널 탭을 여러 개 띄워 두면 어느 세션이 나를 기다리는지 놓치기 쉬워요.

- **🧑‍💻 내 자리**에 와 있는 캐릭터가 있으면 질문이나 승인을 기다리는 중이에요. 그 세션부터 확인하세요.
- 왼쪽 **층별 안내**에서 초록불이 켜진 층이 지금 일하는 프로젝트예요.
- 층을 펼치면 세션마다 `작업 중 / 생각 중 / 확인 필요 / 대기` 상태가 보여요.

### 오래 걸리는 작업을 맡겨 두고 다른 일을 할 때

- 보조 모니터나 브라우저 창 구석에 띄워 두세요.
- 캐릭터가 **☕ 라운지**로 가면 작업이 끝나고 한동안 쉬는 중이라는 뜻이에요.
- 빨간 말풍선과 💦 식은땀이 보이면 도구가 실패한 거예요. 에러 내용이 말풍선과 오른쪽 활동 로그에 나와요.

### 서브에이전트를 많이 쓸 때

- Claude가 서브에이전트를 부르면 **🪑 업무 자리**에서 📞 전화를 걸고, 서브에이전트가 **🛗 엘리베이터**로 출근해요.
- 각자 어느 방에서 무슨 일을 하는지 보여서, 병렬 작업이 어디까지 왔는지 알 수 있어요.
- 일이 끝난 서브에이전트는 Claude 옆으로 와서 보고하고 퇴근해요. 아직 사무실에 남아 있는 서브에이전트는 아직 일하는 중이에요.

### Claude Code와 Codex를 같이 쓸 때

- 같은 프로젝트(같은 작업 폴더)면 두 에이전트가 같은 층에 출근해요.
- Claude는 주황색 ✳, Codex는 초록색 `>_`예요.
- 누가 코드를 고치고 있고 누가 검색 중인지 한 화면에서 비교할 수 있어요.

### 하루를 돌아볼 때

- 오른쪽 **활동 로그**에서 층 전체, 또는 클릭한 캐릭터 한 명의 최근 요청·도구 호출·에러를 시간순으로 볼 수 있어요.
- **화이트보드** 카드에는 그 층에서 가장 최근에 정리된 할 일 목록이 나와요.

## 2. 화면 읽는 법

### 방

| 방 | 의미 |
|---|---|
| 📚 자료실 | 파일을 읽거나 검색하는 중 |
| 💻 개발실 | 코드를 수정하는 중. 앉은 자리의 아이맥 화면에 코드가 흘러요 |
| 🗄️ 서버실 | 명령을 실행하는 중. 랙 불빛이 빨라져요 |
| 🌐 정보검색실 | 웹 검색이나 MCP 도구를 쓰는 중 |
| 🗒️ 회의실 | 계획이나 할 일을 정리하는 중. 화이트보드에 적혀요 |
| 🧑‍💻 내 자리 | 나에게 질문하거나 승인을 기다리는 중 |
| 🪑 업무 자리 | 서브에이전트 호출 중이거나, 방금 일을 마치고 다음 지시를 기다리는 중 |
| ☕ 라운지 | 2분 넘게 쉬는 중. 15분이 넘으면 졸아요 💤 |
| 🛗 엘리베이터 | 새 세션이나 서브에이전트가 출퇴근하는 곳 |

### 말풍선

| 말풍선 | 의미 |
|---|---|
| 흰색 | 지금 하는 일 (도구 이름 · 대상) |
| 💭 파란 구름 | 생각 중. 기록에 생각 요약이 남아 있으면 그 내용이 보여요 |
| ❓ 노란색 | 질문이 있거나 승인을 기다리는 중 |
| 💦 빨간색 | 도구 실패 (8초 동안 표시) |
| 보라색 | 출근, 보고, 퇴근 같은 이벤트 |

### 조작

- **드래그**: 화면 이동
- **스크롤**: 확대·축소, 왼쪽 아래 `⤢` 버튼으로 원래대로
- **캐릭터 클릭**: 그 캐릭터의 활동 로그만 보기. 다시 누르거나 빈 곳을 누르면 해제돼요
- **층 클릭**: 그 층으로 이동. 이동하면 "자동으로 따라가기"가 꺼져요. 다시 켜면 가장 최근에 일한 층을 따라가요

## 3. 상황별 실행 옵션

```bash
# 기본
node agent-office.mjs

# 포트가 겹칠 때
node agent-office.mjs --port 5000

# 오늘 잠깐 쓴 세션까지 오래 남겨 두고 싶을 때 (2시간 동안 '출근' 상태 유지)
node agent-office.mjs --live 120

# 층이 너무 많을 때 (최근 2일 프로젝트만)
node agent-office.mjs --days 2

# Claude Code만, 또는 Codex만 보고 싶을 때
node agent-office.mjs --no-codex
node agent-office.mjs --no-claude

# 세션 폴더가 기본 위치가 아닐 때
CLAUDE_PROJECTS=/path/to/projects CODEX_HOME=/path/to/.codex node agent-office.mjs
```

어디서든 실행하고 싶다면 셸 설정(`~/.zshrc`)에 별칭을 추가하세요.

```bash
alias office='node ~/personal/agent-office/agent-office.mjs'
```

## 4. 항상 켜 두기

### macOS: 로그인할 때 자동 실행

1. node 경로를 확인해요.

   ```bash
   which node   # 예: /opt/homebrew/bin/node
   ```

2. `~/Library/LaunchAgents/com.agent-office.plist` 파일을 만들어요. 경로 두 곳은 내 환경에 맞게 바꿔 주세요.

   ```xml
   <?xml version="1.0" encoding="UTF-8"?>
   <!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
   <plist version="1.0">
   <dict>
     <key>Label</key><string>com.agent-office</string>
     <key>ProgramArguments</key>
     <array>
       <string>/opt/homebrew/bin/node</string>
       <string>/Users/YOU/personal/agent-office/agent-office.mjs</string>
     </array>
     <key>RunAtLoad</key><true/>
     <key>KeepAlive</key><true/>
     <key>StandardErrorPath</key><string>/tmp/agent-office.log</string>
   </dict>
   </plist>
   ```

3. 등록해요.

   ```bash
   launchctl load ~/Library/LaunchAgents/com.agent-office.plist
   # 끄기: launchctl unload ~/Library/LaunchAgents/com.agent-office.plist
   ```

이제 브라우저에서 `http://localhost:4777`을 북마크해 두면 언제든 열 수 있어요.

### 앱처럼 쓰기

Chrome이나 Edge에서 `http://localhost:4777`을 연 뒤 메뉴의 **앱으로 설치**(또는 "바로가기 만들기 → 창으로 열기")를 선택하면 별도 창으로 띄울 수 있어요. 보조 모니터에 고정해 두기 좋아요.

## 5. 내 입맛대로 고치기

모든 코드가 `agent-office.mjs` 한 파일에 있어요. 앞부분은 서버(기록 읽기), 뒷부분(`const PAGE = ...`)은 화면이에요.

### 도구를 다른 방으로 보내기

- **Claude Code**: `catOf()` 함수의 정규식에 도구 이름을 추가하세요.

  ```js
  // 예: 자주 쓰는 MCP 도구를 자료실로
  if (/^(Read|Grep|Glob|...|mcp__notion__search)$/.test(tool)) return 'library';
  ```

- **Codex**: `codexCat()` 함수와 `LIB_CMDS`, `WEB_CMDS` 목록을 고치세요. 예를 들어 `kubectl`을 정보검색실로 보내려면 `WEB_CMDS`에 추가하면 돼요.

방 이름은 `library`, `dev`, `server`, `web`, `meeting`, `desk`, `boss` 중 하나예요.

### 말풍선 문구 바꾸기

화면 코드의 `TOOL_KO`(도구 이름 → 한국어)와 `CAT_ICON`(방 → 아이콘)을 고치면 돼요.

### 캐릭터 색 바꾸기

`AGENT` 객체에서 에이전트별 색을 바꿀 수 있어요. 새 서브에이전트 종류(예: 직접 만든 `code-reviewer`)에 색을 주고 싶으면 한 줄 추가하세요.

```js
const AGENT={claude:{c:'#d97757',n:'Claude'}, ..., 'code-reviewer':{c:'#e11d48',n:'리뷰어'}};
```

### 상태 판단 기준 바꾸기

서버 코드의 `classify()` 함수에서 바꿀 수 있어요.

| 기준 | 기본값 | 위치 |
|---|---|---|
| 승인 대기로 볼 시간 | 12초 | `dur > 12e3 && age > 12e3` |
| 라운지로 가는 시간 | 2분 | `idle < 2 * 60e3` |
| 조는 시간 | 15분 | `idle < 15 * 60e3` |

### 사무실 배치 바꾸기

화면 코드의 `ROOMS`(방 위치와 바닥색), `SPOTS`(캐릭터가 서는 자리), `B(...)` 호출(가구)을 고치면 돼요. 좌표는 타일 단위이고, 전체 바닥은 가로 22 × 세로 20칸이에요.

## 6. 문제 해결

| 증상 | 확인할 것 |
|---|---|
| "세션 폴더를 찾지 못했어요" | `~/.claude/projects`나 `~/.codex/sessions`가 있는지 확인하고, 다른 위치라면 `CLAUDE_PROJECTS`, `CODEX_HOME`을 지정하세요 |
| 층은 있는데 아무도 없음 | 최근 30분 안에 기록이 없는 거예요. `--live 120`처럼 늘려 보세요 |
| 포트 사용 중 에러 | `--port 5000`처럼 다른 포트로 실행하세요 |
| 캐릭터가 계속 "승인 기다리는 중?" | 승인 대기는 추정이에요. 실제로는 오래 걸리는 도구일 수 있어요. `classify()`의 `LONG` 목록에 그 도구 이름을 추가하세요 |
| Codex가 전부 서버실에 있음 | Codex는 대부분 셸 명령을 써서 내용으로 방을 정해요. `LIB_CMDS`에 자주 쓰는 읽기 명령을 추가하세요 |
| 업데이트 후 표시가 이상함 | 세션 기록 형식이 바뀌었을 수 있어요. 아래 점검 스크립트로 구조를 확인하세요 |

### 기록 형식 점검

```bash
node scripts/check-claude.mjs   # Claude Code → scripts/check-report.json
node scripts/check-codex.mjs    # Codex       → scripts/check-codex-report.json
```

두 스크립트 모두 기록의 **구조만** 봐요. 어떤 줄 종류가 있는지, 도구 이름, 생각 기록이 남는지, 서브에이전트 파일 위치 같은 것들이에요. 대화 내용과 명령어 원문은 리포트에 남기지 않아요.
이슈를 올릴 때 리포트를 첨부하면 원인을 찾기 쉬워요. 단, 리포트에는 내 컴퓨터 경로가 들어 있으니 올리기 전에 확인하세요.

## 7. 개인정보와 공유

- Agent Office는 세션 기록을 **읽기만** 하고, 아무것도 저장하거나 밖으로 보내지 않아요.
- 서버는 `127.0.0.1`에서만 열려서 같은 네트워크의 다른 사람도 접속할 수 없어요.
- 팀원과 함께 쓰려면 각자 자기 컴퓨터에서 실행하세요. 각자의 사무실이 보여요.
- 화면에는 프롬프트 일부, 파일 이름, 명령어가 그대로 보여요. 화면 공유나 스크린샷을 할 때 회사 정보가 노출되지 않게 주의하세요.
- 서버를 외부에 열도록(`0.0.0.0`) 고치는 건 권장하지 않아요. 세션 기록에는 코드, 경로, 명령어, 에러 출력이 들어 있어요.
